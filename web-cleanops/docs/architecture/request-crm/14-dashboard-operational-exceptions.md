# 14 - Dashboard and Operational Exceptions

Dashboard shows things to review. It is not the same as Request Manager and not the same as Notification Center.

Candidate dashboard items:

- unassigned requests
- requests without category
- requests without owner
- SLA overdue / near due
- emergency requests
- locked requests with pending access requests
- snoozed requests soon reactivating
- handle-self requests with inactive owner
- booking without staff
- missing cleaning protocol
- missed time report
- unpaid invoices
- system events requiring human review

Dashboard item generation is an automation candidate. The dashboard owns UI and displayed object state; Automation & AI Center owns the action policy and central execution history.
