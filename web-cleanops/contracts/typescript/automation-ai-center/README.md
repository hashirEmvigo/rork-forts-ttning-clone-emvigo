# Contracts

This folder contains portable TypeScript contracts for the Automation & AI Center architecture package.

The contracts cover:

- automation actions
- AI extensions
- approval policy
- module coverage
- runtime safety limits
- runtime guard policies
- feature runtime flags / kill switches
- runtime incidents
- module health
- performance budgets

These contracts are not a generated production API contract. RORK should adapt them to the repository's existing type conventions after inspecting the codebase.
